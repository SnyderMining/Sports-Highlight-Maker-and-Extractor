# \# Sports Highlight Maker and Extractor

# 

# A free Windows application for creating soccer recruiting highlight videos.

# 

# Sports Highlight Maker and Extractor helps parents, players, and coaches draw attention to a specific player in game footage using a spotlight effect.

# 

# \## Features

# 

# \- Add a spotlight effect to highlight a player.

# \- Load videos and select the portions you want to use.

# \- Add music or audio to your highlights.

# \- Export your finished video.

# \- Free to use.

# 

# \## Download and Install

# 

# Visit the \[Releases page](https://github.com/SnyderMining/Sports-Highlight-Maker-and-Extractor/releases/latest) to download the Windows installer.

# 

# 1\. Download the Windows setup `.exe` file.

# 2\. Run the installer.

# 3\. Follow the installation instructions.

# 

# \## Technology

# 

# The application interface is built with HTML, CSS, and JavaScript and packaged as a Windows desktop application using \[Tauri 2](https://tauri.app/). Rust is used for the native desktop application components.

# 

# \## Building from Source

# 

# To build the application, you will need Node.js, Rust, Cargo, and the Windows development prerequisites for Tauri 2.

# 

# See the \[Tauri prerequisites guide](https://v2.tauri.app/start/prerequisites/) for setup instructions.
